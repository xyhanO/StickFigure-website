# StickFigure

Project website for **StickFigure: Enabling Pose-Only IoT Cameras for Privacy-Preserving Edge Vision**, by Aveline Xiaoyuan Han and Chenshu Wu, The University of Hong Kong.

## Publish

In repository Settings → Pages, select **Deploy from a branch**, **main**, **/ (root)**, and Save.

Project URL: https://xyhano.github.io/StickFigure-website/

## Edit

- `index.html`: page content
- `style.css`: styles and responsive layout
- `script.js`: figure viewer
- `assets/`: figures, demo concept image, and paper PDF

All links use relative paths so this site works under `/StickFigure-website/`.
